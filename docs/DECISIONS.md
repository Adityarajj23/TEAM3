# Architectural decisions

1. **SQLite only, two files.** Business data in `tracetest.db`; LangGraph checkpoints in `workflow_checkpoints.db`
   because `langgraph-checkpoint-sqlite` manages its own schema and connection. Both are SQLite, WAL mode, in the
   configurable data directory.
2. **Alembic owns the schema.** The initial migration was autogenerated from the models; startup runs
   `upgrade head`. Models use `render_as_batch` for SQLite-compatible future migrations.
3. **Immutable requirement versions with stable clause keys.** Clause keys are reused when a clause is unchanged
   (same normalised hash) or similar (token Jaccard ≥ 0.5); new clauses get the next free number. This keeps tests
   linked across versions and makes "modified" detectable. Keys can therefore be non-sequential within a version.
4. **Deterministic first, LLM second.** IDs, segmentation, quote checks, coverage, deduplication, status machines,
   script validation and classification are pure Python; the LLM adds interpretation and drafts. Anything the LLM
   returns is validated before it is persisted; ungrounded items are dropped and reported, never repaired by code.
5. **No silent mocks.** MockProvider is active only with `TRACETEST_LLM_MODE=mock` or when an evaluation explicitly
   selects the fixture baseline (stored as `is_fixture = true`).
6. **Historical executions reuse genuine outcomes.** Seeding runs each approved script once per engine build (about
   1 s each) and fans the real outcomes out to 105 historical execution records. Running every record separately
   would take minutes with identical results because the engine is deterministic.
7. **Process sandbox instead of containers.** Keeps the platform runnable on a developer laptop with only Python
   and Node. Defence in depth (AST allowlist, isolated interpreter, clean env, rlimits, netns, socket guard,
   timeouts). Documented as a limitation.
8. **In-process workers with persisted run records.** No Redis/Celery (forbidden). Runs and steps are rows, so
   progress survives page reloads and SSE/polling read from SQLite; interrupted runs are marked failed at startup.
9. **Session cookies over JWT.** Revocable server-side sessions, HttpOnly cookies and a CSRF header suit a
   same-origin SPA.
10. **Hand-written shadcn-style components.** Radix primitives styled with Tailwind, written in-repo instead of the
    shadcn CLI (which needs network templates), keeping the dependency surface small.
11. **Typed requests, hand-typed responses.** Request bodies use Pydantic models (and generated TS types);
    responses are serialiser dicts typed in `frontend/src/types/models.ts`. The OpenAPI drift test guards routes and
    request contracts.
